⚠️ Known Limitations

Where the Virtual Keyboard Cannot Work:

  • Chrome New Tab Page: Chrome security prevents extensions from running on the new tab page
  • Chrome Settings (chrome://settings): Protected by Chrome for security
  • Chrome Web Store: Cannot modify the extension store pages
  • Other chrome:// URLs: All internal Chrome pages are restricted

✅ Workaround:

Simply navigate to any regular website (Google.com, GitHub.com, etc.) and the keyboard will work normally!

Why This Limitation Exists:

This is a Chrome security feature to prevent malicious extensions from tampering with browser settings or stealing sensitive information. All extensions have this limitation.
